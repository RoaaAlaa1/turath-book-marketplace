# Turath

Turath is a local front-end marketplace for pre-loved and recycled books.
It is built with React, TypeScript, TanStack Start, Vite, and Tailwind CSS.

## Development

You need Node.js and npm installed locally.

```sh
cd Grad-front
npm install
npm run dev
```

## Built with

- TanStack Start
- TypeScript
- React
- Tailwind CSS
